备忘，grok注册

发表于2026-08-28|更新于2026-08-28
|总字数:1.6k|阅读时长:7分钟

获取一台可以访问grok的服务器

使用安装脚本安装warp解决大部分服务器被grok屏蔽的问题

安装grok-register-panel

无桌面的服务器需要安装一个Xvfb
sudo apt install xvfb

创建一个systemctl
nano /etc/systemd/system/grok-panel.service

启用服务

安装cloudflare_temp_email

使用github action失败了，遂使用文字教程手动安装，如果有自动安装成功的也可以留言讨论
https://linux.do/t/topic/1666961

在GrokRegister网页控制台进行设置

邮箱服务
API Base：填刚创建的mailapi地址
鉴权模式：x-admin-auth
apikey：在环境变量里设置的ADMIN_PASSWORDS
随机子域：关闭（固定域名）
收信域名：环境变量中设置的DOMAINS
域名接口：/open_api/settings
建号接口：/admin/new_address
其它默认

代理池
socks5://127.0.0.1:1080
检测并启用
此时返回控制台启动任务应该是可以运行了
如果失败在grok-panel.service加上Environment=”PANEL_INCLUDE_TAIL=1”然后在web查看失败日志

安装CLIProxyAPI

参考https://help.router-for.me/cn/introduction/quick-start.html
linux一键安装脚本：curl -fsSL https://raw.githubusercontent.com/router-for-me/cliproxyapi-installer/refs/heads/master/cliproxyapi-installer | bash
启动服务

踩坑：1、如果输出里有类似- “your-api-key-3”的话记得去config.yaml把这行删掉，否则会因为混入了示例/占位符文本而拒绝启动
2、如果要使用网页管理，需要在config.yaml里的remote-management这一段修改

在网页或者config.yaml里把auth-dir改成GrokRegister里设置的目录（Environment=”CPA_AUTH_DIR=/opt/grok-register-panel/cpa_auth”）
然后使用http://你的域名:端口/v1和配置列表API 密钥列表 (api-keys)里面的密钥就可以使用了
